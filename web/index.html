    DATA & PEMELIHARAAN

    Mode simulator. Aplikasi ini memodelkan turnstile di layar — belum terhubung ke perangkat keras. Seluruh aturan dan data berada di server Rust (file data/state.json), dipakai bersama oleh semua perangkat; maksimal 8.000 catatan akses terakhir. NIK adalah data pribadi: layar dan CSV selalu menyamarkan NIK dan server tidak pernah mengirim NIK lengkap ke browser, tetapi file Backup JSON berisi NIK lengkap — simpan dengan aman.
